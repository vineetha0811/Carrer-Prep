BUILD A COMPLETE AI CAMPUS PLACEMENT PREPARATION WEB APPLICATION

1. PRODUCT VISION

Build a modern, responsive, production-quality web application called CampusReady AI.

The application is designed ONLY for final-year engineering students preparing for:

- Campus placements
- Core engineering jobs
- IT/software jobs
- Higher studies entrance/interviews
- General career preparation
- Overall placement readiness

Supported branches in Version 1:

1. Electrical & Electronics Engineering (EEE)
2. Computer Science Engineering (CSE)
3. Electronics & Communication Engineering (ECE)
4. Civil Engineering

The application must not behave like a simple quiz website or question bank.

It should behave like a personal AI placement coach that continuously evaluates the student, identifies weaknesses, creates daily assignments, conducts interviews, improves communication, and adapts future questions based on performance.

Core philosophy

DO NOT simply generate random questions.

The system should follow:

Student Profile → Syllabus/Materials → Assessment → Daily Preparation → Practice → Evaluation → Weakness Detection → Personalized Next Assignment → Mock Interview → Progress Tracking

The ultimate goal is:

«A final-year student should be able to spend approximately 30–40 minutes per day using this application and progressively become more confident and interview-ready over 1–2 months.»

Do not promise job placement or guaranteed selection.

DO NOT ask the AI to generate questions from the entire raw PDF blindly.

First extract and structure the content.

Files → Subjects → Units → Topics → Subtopics → Concepts

Example for EEE:

Electrical Machines

→ Transformer

→ Construction

→ Working principle

→ EMF equation

→ Efficiency

The system should preserve the relationship between:

Branch → Subject → Unit → Topic → Subtopic.

The AI must prioritize content actually present in the student's uploaded syllabus.

IMPORTANT:

9. TECHNICAL DIFFICULTY SYSTEM

Do NOT ask only basic textbook questions.

Use levels:

Level 1 — Basic

Definition and fundamental concepts.

Level 2 — Conceptual

Understanding why/how.

Level 3 — Application

Apply the concept to a real situation.

Level 4 — Tricky

Questions designed around common misconceptions.

Level 5 — Interview Challenge

Questions requiring reasoning and explanation.

Level 6 — Real-world scenario

Give an engineering situation and ask the student to diagnose/explain it.

The system should gradually increase difficulty based on performance.

---

10. EXAMPLE OF QUESTION PROGRESSION

For Electrical Engineering:

Basic:

“What is a synchronous motor?”

Conceptual:

“Why is a synchronous motor not self-starting?”

Application:

“How can a synchronous motor be started?”

Tricky:

“What happens if the mechanical load on a synchronous motor increases beyond the pull-out limit?”

Interview challenge:

“Explain to an interviewer why the average starting torque of a synchronous motor is zero at standstill.”

The same principle should apply to CSE, ECE and Civil topics.

The platform should transform a student's syllabus, materials, resume and project information into a personalized preparation system.

It should combine:

Technical Knowledge + Practical Knowledge + Aptitude + Reasoning + English + Speaking + Interview Skills + Group Discussion + Debate + HR Preparation + Adaptive Learning + Progress Tracking.

The application must continuously answer one question for the student:

«“What should I practice today to become more ready for my placement interview?”»

The system should not merely test students.

It should:

Teach → Ask → Listen → Evaluate → Correct → Explain → Challenge → Track → Adapt → Repeat.

The final experience should feel like having a personal AI placement coach available every day.
